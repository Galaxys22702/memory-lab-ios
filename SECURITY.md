# Security

## Reporting a vulnerability

Please do not disclose credentials, Apple signing material, private keys, or exploitable details in public issues.

Use a private GitHub security report when available. If private reporting is unavailable, contact the repository owner privately before publishing details.

## Secrets

Never commit App Store Connect API keys, Apple certificates, provisioning profiles, private keys, passwords, or recovery codes. CI credentials belong in encrypted GitHub Actions secrets only.

Memory Lab intentionally measures process memory locally and should not be used to collect or transmit unrelated user data.
